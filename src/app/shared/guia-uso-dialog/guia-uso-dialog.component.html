📘 Guía de uso

⚠️ Importante – Privacidad y almacenamiento de datos

Esta aplicación NO almacena ningún dato personal ni financiero del usuario en servidores externos ni bases de datos remotas.

  • Todos los datos se gestionan únicamente en el navegador
  • No se envía información a terceros
  • No existe registro de usuarios ni cuentas

🔐 La única forma de persistir los datos es mediante la exportación manual en formato CSV, que se descarga localmente en tu dispositivo.

  • El archivo CSV es totalmente editable
  • Puedes guardarlo como copia de seguridad
  • Puedes volver a importarlo cuando quieras

💡 Recomendación: realiza exportaciones periódicas para no perder información.

📊 Patrimonio mensual

En esta sección registras el valor de tu patrimonio mes a mes. Cada mes representa una foto completa de tu situación financiera.

  • Cada registro se asocia a un mes concreto
  • El valor se divide en categorías (por ejemplo: Inmuebles, Liquidez, Acciones)
  • Cada categoría puede tener subcategorías (ej. Vivienda habitual, Segunda residencia)
  • El total del mes se calcula automáticamente sumando todas las categorías
  • Si la sección se llama "Inmuebles", automáticamente saldrá un cuadro de texto para añadir la hipoteca pendiente por pagar.

💡 Consejo: introduce siempre el valor total del bien en ese mes, no solo la diferencia.

🏠 Inmuebles y deuda

Los inmuebles permiten registrar tanto el valor bruto como la deuda pendiente asociada (hipoteca).

  • El valor del inmueble se guarda siempre de forma independiente
  • La deuda solo aparece si es mayor que 0
  • El sistema calcula automáticamente el valor neto

Esto permite analizar no solo lo que tienes, sino lo que realmente te pertenece.

🎯 Objetivos financieros

Define objetivos para controlar hacia dónde quieres llevar tu patrimonio.

  • Puedes definir un objetivo total global
  • También objetivos individuales por categoría
  • El progreso se muestra visualmente mediante barras

📈 Ideal para visualizar si estás avanzando según lo previsto.

📈 Patrimonio general

Aquí tienes una visión global y analítica de tu evolución financiera.

  • Distribución del patrimonio por categorías
  • Evolución mensual con gráficos de barras y líneas
  • Comparación entre meses
  • Análisis de deudas actuales

Los gráficos se pueden filtrar por categorías y rango de meses.

💾 Importar y exportar datos

Puedes exportar todos tus datos a CSV o importar datos existentes.

  • Compatible con hojas de cálculo
  • Ideal para copias de seguridad
  • Permite migrar datos desde otras herramientas
